Authentication: the token is presented in the Authorization header in the form 'Bearer <token>'. Your token: ${AUTH_TOKEN}.
Token scope: a session token belonging to the superadmin account, obtained by signing in to the admin API as that account; the account's username and password are upstream's published defaults, the same for every instance, because the instance config declares no others. The account holds the SuperAdmin role. At this version's default configuration a session lasts one year. No other users, roles, or credentials exist beyond what the seed creates.
