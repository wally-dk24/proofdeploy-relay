# WO-R4-G: reach and provoke — sign in once, aim at changed code, varied states
Worktree `/home/claude/wt-r4-gen`, branch `fix/lean-r4-gen`. Files: `proofdeploy/lean/generate.py`, `proofdeploy/lean/http.py`, tests. Register: R7, R2.

1. **Sign in once per side per run.** `ScenarioRunner` performs the contract's login once, caches the token, and reuses it for every authenticated step until a response is 401/403, then signs in again once (counted). Login requests count against the budget; record `logins` in the loop stats. Today every scenario logs in. Test: 50 authenticated scenarios → 1 login (plus re-logins only after a 401).
2. **Aim at the changed code.** After a first pass that sends one request per operation, rank operations by the number of changed executable lines their requests executed (from the per-request coverage contexts we already record), and spend the remaining budget on the top-ranked ones: input variants (boundary numbers 0/-1/max, empty string, null for optional fields, very long strings, unicode, constants mined from the changed lines), plus create→read/list/update/delete chains on the same record. Stop early when every changed line is covered. Deterministic for a fixed seed. Test with the golden app: the operation reaching the changed line receives most of the remaining budget.
3. **Varied states through the API.** A seeding stage before probing: for every create operation (POST with a JSON body schema) create 3 records in different shapes — all optional fields omitted; all optional fields set (strings at schema maxLength or 255, unicode); references to other records set to an existing id, to a deleted record's id, and omitted. Then list each collection, read each record, update one field, delete one record. Runs identically on both sides inside each 2×2 run (part of every scenario replay), never stored outside the run. Invalid shapes the app rejects (4xx) are kept as data, not retried forever (one 400-repair attempt as today). Test with golden: records with and without optional fields exist before probing.
